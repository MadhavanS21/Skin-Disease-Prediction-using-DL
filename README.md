# Skin Disease Prediction Using DenseNet121

This project focuses on developing a **deep learning-based skin disease classification system using DenseNet121**. The model analyzes skin images and predicts the corresponding disease category based on visual patterns present in the image.

The project uses **DenseNet121**, a pretrained convolutional neural network, with **transfer learning** to leverage features learned from the ImageNet dataset. This allows the model to identify relevant image characteristics such as texture, color, shape, and lesion patterns without training an entire deep learning model from scratch.

## Dataset

The dataset used for this project is the **Skin Diseases Image Dataset**, available on Kaggle.

**Dataset:** Skin Diseases Image Dataset
**Source:** Kaggle
**Link:** https://www.kaggle.com/datasets/ismailpromus/skin-diseases-image-dataset

The dataset contains images of different skin disease categories that are used for training, validating, and testing the DenseNet121 model.

## Key Features

* Skin disease image classification using **DenseNet121**
* Transfer learning with pretrained ImageNet weights
* Image preprocessing and augmentation
* Model training and validation
* Performance evaluation on unseen test data
* Achieved approximately **72% test accuracy**

## Objective

The objective of this project is to explore the application of **deep learning and transfer learning for automated skin disease image classification** using DenseNet121.
